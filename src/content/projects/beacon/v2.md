## what changed

- **a new backend.** Convex is gone. an Effect API on a Cloudflare Worker keeps everything in D1, with Drizzle for the schema and migrations
- **snapshots instead of subscriptions.** the apps keep persisted TanStack Query snapshots of each trip, so a trip opens from the saved copy and then refreshes
- **a web app.** TanStack Start, next to the Expo app, sharing contracts, design tokens, and UI logic
- **agent access.** Claude and ChatGPT connect over MCP with OAuth. each tool has a policy, and some actions need your approval
- **one deploy definition.** Alchemy defines the Worker, D1, and the web app, with a preview stage for each pull request

## features

- **shared trips.** Owner, Member, and Viewer roles, and a status that follows the trip's dates
- **invites.** a link that shows a preview of the trip before you join
- **places and itineraries.** saved places, ordered itineraries in each destination's timezone, and a home base
- **guide import.** paste a food or travel guide's URL, and Beacon finds the places it names
- **suggestions.** members suggest places, react, and comment
- **weather and currency.** weather for the trip and currency conversion
- **Apple Sign-In.** one tap to get started

## tech stack

- Mobile: Expo, React Native, Expo Router, Uniwind
- Web: TanStack Start, React, Vite
- API: Cloudflare Workers, Effect v4, D1, Drizzle
- Auth: Better Auth with Sign in with Apple, and an OAuth provider for agents
- State: TanStack Query and Jotai
- Deploy: Alchemy, EAS for TestFlight
- Tooling: Turborepo, Bun, Ultracite
