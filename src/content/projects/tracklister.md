# Tracklister

Tracklister is a web application designed to help DJs easily create and format track listings from their mixes. This tool streamlines the process of organizing and sharing track information.

## Features

- Easy track input and formatting
- Multiple export formats
- Time stamp support
- Copy-paste functionality

## Technology Stack

- Frontend: React
- Backend: Node.js
- Database: MongoDB

## Development Status

Currently in development with core features implemented.

## Future Plans

- Integration with streaming platforms
- Mobile-responsive design
- Social sharing features
