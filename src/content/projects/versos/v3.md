## what changed

Tracklister became Versos. same idea, rebuilt from the ground up: Apple Music instead of Spotify, a proper job queue instead of one long request, and Effect running the backend.

## how it works

1. **Paste**
   - a setlist, mix tracklist, album listing, whatever is in the comments

2. **Parse**
   - Gemini Flash-Lite turns the text into artist and track pairs through the AI SDK
   - if the model fails, a regex parser takes over so the job still finishes

3. **Queue**
   - a BullMQ worker picks up the job, stores the parsed tracks in Postgres, and tracks its status

4. **Match**
   - tracks are matched against Apple Music concurrently with fuzzy scoring
   - retries back off exponentially, and results are cached per platform in Redis

5. **Playlist**
   - the playlist is created on whichever streaming platform you've connected

## architecture

the API is Hono with **Effect** underneath. every service is a layer, so dependencies resolve at compile time and errors are typed all the way through. a platform registry picks the streaming service from your preference, which tokens are still valid, and a priority order.

the frontend is TanStack Start with file-based routing, tRPC for the API, Jotai for client state, and `nuqs` for anything that belongs in the URL.

## tech stack

- Frontend: TanStack Start, React 19, Tailwind v4, shadcn/ui, Jotai, Motion
- Backend: Hono, Effect, tRPC, BullMQ
- Data: PostgreSQL with Drizzle, Redis
- AI: AI SDK with Gemini Flash-Lite
- Auth: Better Auth with email, password, and passkeys
- Observability: OpenTelemetry, Langfuse
- Tooling: Turborepo, Bun, Ultracite, Vitest
